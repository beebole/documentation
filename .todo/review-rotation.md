# Review rotation

Every `/release` fully re-reviews the pages reviewed longest ago, "never" first, then the oldest date (release skill, step 3, "Rotation audit"). A page's date moves to today whenever it goes through every `/review` check, in a release or on its own (review skill, step 5). Pages a release drafted or updated are reviewed in that release and get its date too.

Seeded 2026-10-04 from git history: the last `release: apply review fixes` commit that touched each page. Releases merged by squash since 2026-09-07 left no such commit, so most pages start at "never".

Legacy pages are a frozen archive and are not listed.
